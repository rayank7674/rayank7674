## 🚀 Selected Projects

### Wind Pressure Reconstruction — FIU Research
Developed a Gaussian process regression framework with greedy sensor selection to reconstruct rooftop wind pressures from high-frequency experimental data, achieving R² > 0.90 using 30–35% of the original pressure taps while retaining uncertainty quantification.

### [HackCMU — StormReady](https://hack-cmu.vercel.app)
A hurricane preparedness application designed to help households assess risk and prioritize practical readiness actions using location-based data and deterministic decision logic.

### [HurricaneX](https://github.com/rishant3441/HurricaneX)

### CentraMeet — Full-Stack Meeting Optimizer
Built a full-stack meeting optimizer using FastAPI, Next.js, and Firestore to identify meeting locations that minimize maximum weighted travel time.

### BlockParty — ScottyLabs
Developing a Next.js platform for CMU meal-plan analytics, helping students track block usage against semester pacing targets and plan around breaks.
